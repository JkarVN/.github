# 🤖 GravityBot (ZGravityBot)

### The Internal Automation Engine of Zane Authors

GravityBot is a high-performance software development assistant specifically designed for **Zane Authors**—a development group within the **Sao Tin Developer Team** (part of the **Sao Tin Group** ecosystem). We are an independent community of tech enthusiasts, not a corporate or legal entity.

Unlike fully autonomous systems, GravityBot operates as a powerful assistant, executing technical tasks based on direct requests from our members to maintain high-velocity workflows across our projects.

-----

## 🚀 Key Capabilities

  * **🛠 Request-Driven Execution:** Automates code updates, commit management, and branch merging based on specific instructions from team members.
  * **🌐 Multi-IDE Integration:** Supports seamless workflows across modern development environments including **Google Antigravity**, **Amazon Kiro**, and **ByteDance Trae**.
  * **🧠 Multi-Model AI:** Leverages the combined intelligence of **Google Gemini** and **Anthropic Claude** for code assistance, logic validation, and data optimization.
  * **🏗 Ecosystem Scaffolding:** Serves as the core engine for CI/CD, deployment, and maintenance of flagship Zane Authors projects like LanChi and Zane V8.

-----

## 🛡️ Operational Principles

> [\!IMPORTANT]
> **Human-in-the-Loop:** GravityBot functions as an execution tool, not a replacement for human creativity. Every line of code or change assisted by the bot undergoes a rigorous review process by the **Zane Authors core team** before being officially committed.

-----

## 📂 Supported Projects

  * **[LanChi MCP Engine](https://github.com/Zane-Authors/LanChi):** A high-performance, premium Model Context Protocol (MCP) Server. It bridges the gap between **AgentSkills** (dynamic actions) and **OneContext** (hybrid long-term memory), providing a state-of-the-art ecosystem for AI Agents.
  * **[Zane V8 (Z8)](https://github.com/Z8-JS/Z8):** A high-performance JavaScript runtime built on top of Google's V8 engine. GravityBot assists in optimizing the **C++ core** and managing automated testing pipelines.
